# Viajes MFC - PFY2202 Semana 5

Aplicación React desarrollada para la evaluación sumativa de Desarrollo Frontend II.

## Funcionalidades

- Listado de destinos mediante API REST mock.
- Consulta de vuelos y hoteles mediante API GraphQL mock.
- Información de precios, fechas y disponibilidad.
- Navegación con React Router.
- Manejo de carga y errores.
- Página 404.
- Diseño responsive con Material UI.
- Backend simulado mediante MSW.
- Apollo Client para consultas GraphQL.

## Tecnologías

- React
- Vite
- JavaScript
- React Router
- Material UI
- Apollo Client
- GraphQL
- MSW
- GitHub Pages

## Ejecutar localmente

npm install
npm run dev
